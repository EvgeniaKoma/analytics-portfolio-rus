# Data Analytics Portfolio — Evgenia Komarovskaya

[Русский](README.md) | **English**

Educational projects in product analytics, A/B testing, statistical analysis, and experimentation.

The projects use synthetic data and focus on analytical reasoning, experiment quality, interpretation of uncertainty, and business implications.

## Projects

| Project | Main question |
|---|---|
| [01. Subscription Pricing A/B Test](01-subscription-pricing-ab-test/README.en.md) | Can higher conversion offset a lower subscription price? |
| [02. Subscription Renewal Proxy Metrics](02-proxy-metrics/README.en.md) | Which early user behaviors could indicate future subscription renewal? |
| [03. A/A and A/B Simulations](03-simulations/README.en.md) | How do statistical tests behave under the null hypothesis, and how does sample size affect power? |
| [04. CTR Experiment Analysis](04-ratio-metrics/README.en.md) | How do different statistical methods affect sample size estimates and the interpretation of ratio metrics? |

Each project includes a Jupyter notebook with the analysis and saved results. Selected projects also contain PDF presentations. Notebooks and presentations are in Russian; these English summaries explain the questions, methods, and findings.

## Tools and Methods

Python, pandas, NumPy, SciPy, statistical hypothesis testing, bootstrap, experiment design, and simulation.
