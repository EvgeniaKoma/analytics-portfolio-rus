# Выбор прокси-метрик для раннего сигнала продления подписки

**Русский** | [English](README.en.md)

Учебный кейс из курса по A/B-тестированию.

## Данные

Синтетический датасет со сведениями о клиентах, активности и дополнительных услугах: количественные и качественные характеристики.

## Задача

Выбрать метрики-кандидатов на ранний сигнал продления подписки.

## Подход

- Составлен перечень характеристик, определяющих хорошую прокси-метрику.
- Проведён корреляционный анализ имеющихся метрик для выбора кандидатов на ранний сигнал продления подписки с помощью трёх методов: корреляции Пирсона, Cramér’s V (связь между категориальными переменными) и point-biserial correlation (связь между бинарной и непрерывной переменными).
- Проверено соответствие метрик, определённых на этапе корреляционного анализа, ключевым характеристикам хороших прокси.
